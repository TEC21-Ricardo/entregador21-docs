# Etapa 3: Cadastro de Usuários

## Objetivo

Cadastrar usuários administrativos e motoboys no Entregador21 após a criação do ambiente de produção.

## Responsáveis

- 👤 **Daniel**: Fornecimento de credenciais SGC
- 👤 **Suporte/Implantação**: Cadastro via SGC
- 👤 **Cartório**: Fornecimento de dados dos usuários

---

## Passo 1: Coleta de Dados de Usuários

### Solicitar ao Cartório

Solicite os seguintes dados:

#### 📋 Usuários Administrativos

```
Nome completo:
CPF:
```

#### 📋 Usuários Motoboys

```
Nome completo:
Número do celular:
```

**Mensagem para o cartório:**

```
Pessoal, vocês podem me passar:

Usuários administrativos:
- Nome completo
- CPF

Usuários Motoboys:
- Nome completo
- Número do celular

Para cadastrarmos no Entregador21.
```

---

## Passo 2: Cadastro no SGC (Sistema de Gestão Entregador21)

### O que é o SGC

SGC (Sistema de Gestão Entregador21) é um sistema **desktop** que será utilizado para cadastrar os usuários administrativos.

### Acessar o SGC

**Credenciais fornecidas por Daniel:**
- Código da empresa
- Usuário
- Senha

Daniel fornecerá essas credenciais após a criação do ambiente.

### Cadastro dos Usuários Administrativos

De posse dos dados coletados, realize o cadastro dos usuários administrativos no SGC.

**Após o cadastro no SGC:**

Repassar os mesmos dados dos usuários administrativos para o Daniel criar o usuário e senha para acessar o ambiente web.

---

## Passo 3: Gerar Credenciais de Acesso Web

### Solicitar ao Daniel

Com os usuários cadastrados no SGC, solicite ao Daniel as credenciais de acesso ao ambiente web:

**Dados que Daniel fornecerá:**
- Usuário (Email)
- Senha
- Link de acesso ao ambiente

**Daniel retornará:**
- Dados (usuário e senha) de acesso dos usuários administrativos
- Link de acesso ao ambiente

---

## Passo 4: Comunicar Credenciais ao Cartório

### Repassar Dados

Repassar ao cartório:
- Link de acesso ao ambiente
- Usuário
- Senha

**Exemplo:**

```
URL: https://app.entregador21.com/cartorio-[codigo]
Usuário: usuario@cartorio.com.br
Senha: XXXXXX
```

---

## Passo 5: Cadastro dos Usuários Motoboys

### Onde Cadastrar

O cadastro dos usuários motoboys é realizado **dentro da própria plataforma do Entregador21**.

O usuário administrativo fará o cadastro através da plataforma web usando as credenciais fornecidas.

---

## Checklist da Etapa 3

- [ ] Dados de usuários administrativos coletados
- [ ] Dados de motoboys coletados
- [ ] Cadastro realizado no SGC (usuários administrativos)
- [ ] Solicitação de credenciais enviada ao Daniel
- [ ] Credenciais recebidas de Daniel
- [ ] Credenciais comunicadas ao cartório
- [ ] Usuários motoboys cadastrados na plataforma
