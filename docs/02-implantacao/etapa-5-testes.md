# Etapa 5: Testes de Rotina

## Objetivo

Realizar testes de rotina do fluxo de intimação com dados reais.

## Responsáveis

- 👤 **DEVs Sistema Cartório**: Gerar lote de teste
- 👤 **Suporte/Implantação**: Coordenar testes
- 👤 **Cartório**: Executar testes

---

## Passo 1: Solicitar Lote de Teste

### Contato com DEVs do Cartório

Entrar em contato com os desenvolvedores do sistema do cartório e solicitar:

- Uma carga de um lote de intimações para testes de rotina
- Dados variados para testar o fluxo completo

---

## Passo 2: Testar o Fluxo Completo

### Testes de Rotina

Os testes devem cobrir:

1. **Envio de intimações** - Importação dos dados
2. **Importação das baixas** - Retorno dos status de entrega
3. **Imagens/ARdigital (PDF)** - Vinculados às entregas

### ⚠️ Importante

**Testar a importação das entregas com situação de ausente**

---

## Checklist da Etapa 5

- [ ] Lote de teste solicitado aos DEVs
- [ ] Lote de teste recebido
- [ ] Testes de envio realizados
- [ ] Testes de importação de baixas realizados
- [ ] Testes de imagens/ARdigital realizados
- [ ] Testes com situação "ausente" realizados
- [ ] Todos os testes aprovados

## Próximo Passo

Após aprovação nos testes, o cartório está pronto para operação.
