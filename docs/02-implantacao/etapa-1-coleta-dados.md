# Etapa 1: Coleta de Dados do Cartório

## Objetivo

Coletar informações do cartório necessárias para criar o ambiente de produção.

---

## Passo 1: Verificar Contato com Anderson

Verificar com o Anderson o contato direto do responsável pelo setor de protesto.

---

## Passo 2: Criar Grupo de Comunicação

Criar grupo no WhatsApp (Anderson ou Suporte) com o responsável pelo setor de protesto.

---

## Passo 3: Solicitar Informações

Entrar em contato com o responsável pelo setor de protesto e requerer as seguintes informações:

### Mensagem Padrão

```
Pessoal, vocês podem me passar:

- Nome do cartório
- Logomarca (se tiver)
- CNPJ
- Endereço

Para gerarmos e montarmos o ambiente de vocês.
```

---

## Checklist da Etapa 1

- [ ] Contato com Anderson confirmado
- [ ] Grupo WhatsApp criado
- [ ] Mensagem de solicitação enviada
- [ ] Dados recebidos do cartório
- [ ] Dados documentados
